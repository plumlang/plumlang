# Governance

Plumlang is an Elixpo production, maintained in the `plumlang` GitHub organisation. The lead maintainer is @Circuit-Overtime. Material scope, release, governance, and lifecycle changes require maintainer review.

Changes to the language itself go through a language proposal issue and land as a change to `docs/spec.md`. Licensing, commercial terms, repository transfer, security disclosure, publication, and project-status decisions require explicit human approval by the lead maintainer. Canonical public status is recorded at [elixpo.com](https://elixpo.com).

# Need help?

A quick map of where to take what:

| You want to… | Go here |
|---|---|
| Report a bug | [New bug report issue](https://github.com/plumlang/plumlang/issues/new?template=bug_report.yml) |
| Propose a language change | [New language proposal](https://github.com/plumlang/plumlang/issues/new?template=language_proposal.yml) |
| Propose a standard library module | [New library proposal](https://github.com/plumlang/plumlang/issues/new?template=stdlib_proposal.yml) |
| Read the docs | [README](README.md) → [PREAMBLE.md](PREAMBLE.md) → [CONTRIBUTING.md](CONTRIBUTING.md) |
| Disclose a security issue | [Security policy](docs/SECURITY.md) |
| Ask about a commercial licence | Email **hello@elixpo.com** |
| Ask a general question | [Discussions](https://github.com/plumlang/plumlang/discussions) or **hello@elixpo.com** |
| Read the rules | [Code of Conduct](CODE_OF_CONDUCT.md) |

## Response times

We aim for:

- **Security advisories:** within 3 working days.
- **Commercial licensing:** within 3 working days.
- **Bug reports:** within a week.
- **Proposals / PRs:** within two weeks.

If you've been waiting longer, nudge us.

## A good bug report

1. `plum version` output and your operating system.
2. The smallest program that shows the problem.
3. What it printed, and what you expected.
